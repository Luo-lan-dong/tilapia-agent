# Steering v1 Spec（执行中插话：队列提升 + 配额重置）

> 关联：[ADR-045](../adr/045-orchestrator-steering-v1.md) · [Harness](./045-steering-v1-harness.md) · [Changes](./045-steering-v1-changes.md)
> 路线图定位：P5（缺陷清单最后一项），tilacode 探查档案章节二 Steering 对标。

## 功能描述

AI 回复进行中，用户可随时插入新消息：

1. 插话经投递端点进入会话级队列（不丢）；
2. Orchestrator 在工具轮边界 / 收尾判定 / 强制收尾前把队列消息提升进
   prompt（AI 本轮内即可感知修正方向），并重置步数配额；
3. 前端回复中解禁输入，插话显示为「已排队」气泡，提升后转正常。

## 用户故事

- **US-1（方向修正）**：AI 连续调用工具处理任务时，用户发现方向错了，
  立即插话「不对，用方案 B」——AI 在下一个工具轮边界看到修正，调整路径，
  不烧完剩余配额。
- **US-2（插话不丢）**：即使模型本轮没有调用工具（直接回答中）或触发
  doom loop / 轮上限强制收尾，排队插话也会被提升进收尾 prompt 或延续对话，
  永不静默丢弃。
- **US-3（竞态安全）**：用户点击发送的瞬间流恰好结束——投递端点返回 409，
  前端自动降级为普通发送，插话作为下一轮首条消息。

## 核心流程

```
用户在回复中输入并发送
  → POST /tasks/build/chat/steer {session_id, content}
      ├─ 会话无活跃流（409）→ 前端降级为普通 sendMessage
      └─ 成功入队 → 前端显示「已排队」气泡

chat_stream（进行中）：
  工具轮执行完成 ────────────┐
  收尾判定（无 tool_calls）──┤→ drain 队列
  doom/轮上限强制收尾前 ─────┘
      ├─ 队列空 → 按原逻辑继续/收尾
      └─ 有插话：
            rounds_used = 0（步数配额重置）
            user 消息 append 进 prompt_messages
            yield steering_applied {content}   ← 前端清除排队标记
            yield _steering_messages {messages} ← 内部，端点落库用
            继续下一轮（模型基于插话 + 工具结果回答）

流结束持久化（端点）：
  前端回传历史 → 工具轨迹 → 插话 user 消息 → assistant 最终回复
```

## 判定细则

| 项 | 规则 |
|----|------|
| 活跃流判定 | 模块级注册表 `open(session_id)`/`close(session_id)`，与 chat_stream 生命周期一致 |
| 提升检查点 | ①工具轮执行完成后；②收尾判定时（无 tool_calls 且即将 done）；③doom/轮上限收尾前 |
| 配额重置 | 提升即 `rounds_used = 0`（对齐 tilacode：新输入重置步数配额） |
| 落库位置 | 工具轨迹之后、assistant 最终回复之前（覆盖式保存的插入协调） |
| 前端降级 | steer 返回 409（无活跃流竞态）→ 自动转普通 sendMessage |
| 队列残留 | 正常路径收尾前已 drain；close 兜底丢弃（防御性） |

## 降级链路

| 场景 | 行为 |
|------|------|
| 会话无活跃流 | 409 → 前端降级普通发送 |
| 投递后流异常终止 | close 丢弃残留（防御性）；前端气泡保留，用户可重发 |
| 多条插话排队 | 边界一次全部提升（按投递顺序） |
| 插话与 overflow 压缩同时 | 插话提升发生在流成功后边界，与 overflow 重跑（while 内）不冲突 |

## 验收标准

- [ ] 插话投递端点：活跃流入队成功、无活跃流 409；
- [ ] 工具轮边界提升：下一轮流式调用的 prompt 含插话 user 消息；
- [ ] 收尾前提升：无工具调用直接回答时插话延续对话（不 done）；
- [ ] doom/轮上限收尾前提升：收尾 prompt 含插话；
- [ ] 配额重置：提升后可继续跑满 max_rounds 轮；
- [ ] 落库顺序：历史 → 轨迹 → 插话 → 回复；
- [ ] 前端：回复中可发送、排队气泡、steering_applied 清除标记、409 降级；
- [ ] 不投插话时全量回归与现状一致。
