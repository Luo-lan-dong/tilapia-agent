# 系统设置页布局改版变更清单（Changes）

> 依据设计稿 `设计稿/系统设置`（v2 双栏布局）对系统设置页做纯前端布局重排。
> 关联决策：ADR-030（模型管理）/ ADR-031（网络配置与端口）/ ADR-033（AI 智能调度）——
> 功能与接口零改动，不新开 ADR；本文件按 ui-layout-changes 先例登记。

## 一、设计稿对比

| 区块 | 原版（现状） | 设计稿 v2 |
|---|---|---|
| 页面布局 | 单列竖排三卡，maxWidth 640 | **双栏 grid 14fr:10fr**（≈58%/42%），gap 16 |
| 左栏 | 模型管理（窄卡） | 模型管理 panel-card（占满左栏） |
| 右栏 | —（两张卡叠在左栏下方） | AI 智能调度卡 + 网络配置卡（flex column, gap 16） |
| 卡片内边距 | antd 默认 24px | 20px（对齐 panel-card__section） |
| 响应式 | 固定窄宽 | 窄屏（<lg）自动单列 |

模型管理（标题+描述+添加按钮头部、模型/服务商/操作表格）、AI 调度横向行、
网络表单项与按钮组——三个子组件内容与设计稿一致，未改动。

## 二、变更清单

| # | 文件 | 类型 | 明细 | 作用 |
|---|------|------|------|------|
| 1 | src/pages/Settings.tsx | 修 | 移除 maxWidth 640 单列；改为 Row/Col 双栏（xs=24 lg=14/10）；panelCardStyle/panelCardBodyStyle 统一卡片外观（20px 内边距）；右栏 flex column gap 16 | 布局重排对齐设计稿 |

## 三、验证

- 前端 tsc / eslint 通过；功能（表单保存、模型增删切换、调度开关）零改动。
- 浏览器验证：双栏布局渲染正确（见联调记录）。
