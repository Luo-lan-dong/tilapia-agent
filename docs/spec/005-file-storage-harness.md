# 文件存储与交付物管理模块 Harness

## 1. 测试金字塔

```
        /\
       /  \
      / E2E \          少量：完整上传-聚合-下载链路
     /--------\
    /  集成测试  \       中量：MinIO + API + 元数据库
   /--------------\
  /    单元测试     \      大量：路径生成、元数据校验
 /------------------\
```

## 2. 单元测试清单

| 测试对象 | 测试场景 | 通过标准 |
|---------|---------|---------|
| 路径生成 | 生成交付物路径 | 符合 `deliverables/{task_id}/{filename}` |
| 路径生成 | 生成需求资料路径 | 符合 `requirements/{task_id}/{filename}` |
| 文件名安全处理 | 含特殊字符的文件名 | 被安全转义或拒绝 |
| 元数据解析 | 解析 MinIO 返回的 ETag/Size | 字段类型正确 |
| 文件类型校验 | 上传允许类型 | 通过 |
| 文件类型校验 | 上传禁止类型 | 拒绝 |

## 3. 集成测试清单

| 测试对象 | 测试场景 | 通过标准 |
|---------|---------|---------|
| 预签名上传 | 请求上传 URL | 返回有效 URL，过期时间正确 |
| 文件直传 | 使用预签名 URL 上传 | MinIO 中存在对象 |
| 元数据记录 | 上传完成后通知中枢 | 数据库 file_records 表有记录 |
| 交付物查询 | 按 task_id 查询 | 返回该任务全部交付物 |
| 下载链接生成 | 请求下载 | 返回有效预签名下载 URL |
| 交付物聚合 | 多个子任务完成 | 中枢能列出完整交付物清单 |

## 4. 契约测试清单

| 测试对象 | 测试场景 | 通过标准 |
|---------|---------|---------|
| 上传 URL 接口 | POST /api/v1/files/upload-url | 返回 url、key、expires_at |
| 文件元数据接口 | POST /api/v1/files/metadata | 响应符合统一格式 |
| 交付物列表接口 | GET /api/v1/tasks/{id}/deliverables | 返回数组含 name/type/path/size |

## 5. E2E 测试场景

### 场景 1：用户上传需求文档

1. 用户在前端选择需求文档上传。
2. 前端请求预签名上传 URL。
3. 前端直传到 MinIO。
4. 上传完成后通知中枢。
5. 中枢记录文件元数据。
6. Agent 执行任务时可读取该文档。

### 场景 2：Agent 上传交付物并聚合

1. 编程 Agent 完成官网开发。
2. Agent 将代码压缩包上传到 `deliverables/{task_id}/project-source.zip`。
3. Agent 上报交付物元数据。
4. 视频 Agent 完成宣传片并上传视频。
5. 中枢聚合所有交付物。
6. 用户在前端一键下载完整交付包。

## 6. CI 门禁

- 单元测试覆盖率 ≥ 70%。
- MinIO 集成测试通过。
- 文件路径和元数据格式校验通过。
- ruff / black / mypy 检查通过。
