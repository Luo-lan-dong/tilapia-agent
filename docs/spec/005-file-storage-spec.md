# 文件存储与交付物管理模块 Spec

## 1. 功能描述

为整个 OPC 系统提供统一的文件存储底座，支持：

- 用户上传需求资料、参考资料。
- Agent 节点上传执行过程中的中间产物和最终交付物。
- 前端下载、预览、归档交付物。
- 所有节点通过统一路径访问文件，禁止点对点传输。

## 2. 用户故事

- 作为用户，我希望上传需求文档供 Agent 参考。
- 作为 Agent，我需要将生成的代码包、视频成片上传到统一存储。
- 作为用户，我希望在前端直接下载或预览交付物。
- 作为系统，我希望按任务 ID 归档所有相关文件。

## 3. 核心流程

### 3.1 文件上传流程

```
上传请求
    ↓
中枢生成预签名上传 URL
    ↓
客户端/Agent 直传 MinIO
    ↓
MinIO 回调/客户端通知上传完成
    ↓
中枢记录文件元数据
```

### 3.2 交付物归档流程

```
子任务完成
    ↓
Agent 上传交付物到 deliverables/{task_id}/
    ↓
Agent 上报交付物元数据
    ↓
中枢聚合所有子任务交付物
    ↓
生成完整项目交付包
    ↓
用户下载
```

## 4. 降级链路

| 异常场景 | 降级策略 |
|---------|---------|
| 存储服务不可用 | 返回 503，任务暂停上传，定时重试 |
| 上传文件过大 | 返回 413，限制单文件大小（如 2GB） |
| 文件格式不支持 | 返回 400，拒绝上传 |
| 交付物上传失败 | Agent 上报失败，中枢标记任务失败 |
| 文件元数据丢失 | 通过存储桶扫描任务目录重建元数据 |

## 5. 验收标准

- [ ] 支持通过预签名 URL 上传文件。
- [ ] 文件路径按 `deliverables/{task_id}/{filename}` 规范存储。
- [ ] 前端可下载、预览常见文件类型（图片、视频、文档、压缩包）。
- [ ] 交付物元数据正确记录（类型、大小、路径、创建时间）。
- [ ] 任务完成后可一键打包下载全部交付物。
- [ ] 大文件上传支持断点续传或分片上传。
