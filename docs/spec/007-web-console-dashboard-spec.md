# 前端管理控制台仪表盘模块 Spec

## 1. 功能描述

为 OPC 系统提供一个最小化的 Web 管理控制台，让使用者能够：

- 提交自然语言需求创建任务。
- 查看集群 KPI（总任务数、进行中、已完成、在线节点数）。
- 查看任务队列列表及实时状态/进度。
- 查看在线 Agent 节点列表及负载状态。

本阶段**不做**：节点管理详情页、任务队列详情页、告警中心、日志审计、系统设置、交付物下载。

## 2. 用户故事

- 作为 OPC 用户，我希望在网页上输入需求并创建任务，而不是直接调用 API。
- 作为 OPC 用户，我希望在首页看到当前有多少任务在运行、多少节点在线。
- 作为 OPC 用户，我希望看到任务进度实时更新，确认 AI 员工正在执行。

## 3. 核心流程

### 3.1 创建任务

```
用户进入仪表盘
    ↓
点击「新建任务」
    ↓
输入自然语言需求
    ↓
调用 POST /api/v1/tasks
    ↓
任务创建成功，任务列表自动刷新
```

### 3.2 查看集群状态

```
仪表盘加载
    ↓
并行请求 GET /api/v1/tasks 和 GET /api/v1/agent-nodes
    ↓
渲染 KPI 卡片、任务列表、节点列表
    ↓
每 5 秒轮询刷新
```

### 3.3 任务状态流转展示

```
pending → assigned → running → completed/failed
    ↓
任务列表中的状态标签和进度条同步更新
```

## 4. 降级链路

| 异常场景 | 降级策略 |
|---------|---------|
| 后端 API 不可用 | 显示错误提示，提供重试按钮 |
| 创建任务失败（DeepSeek 不可用） | 显示后端返回的错误信息 |
| 轮询失败 | 保持当前数据，提示"连接异常"，继续尝试 |
| 无任务/无节点 | 展示空状态，引导用户创建任务或注册节点 |

## 5. 验收标准

- [ ] 可通过 `npm run dev` 启动前端开发服务器。
- [ ] 首页展示与后端数据一致的 KPI 卡片。
- [ ] 任务列表展示任务 ID、名称、类型、状态、进度、分配节点。
- [ ] 节点列表展示节点名称、类型、状态、负载。
- [ ] 可通过表单创建任务，创建成功后列表自动刷新。
- [ ] 页面每 5 秒自动轮询刷新数据。
- [ ] 前端项目通过 ESLint/TypeScript 类型检查。
- [ ] 文件长度符合 coding-standards.md 要求。

## 6. 新增/修改后端接口

### 6.1 新增：查询任务列表

```http
GET /api/v1/tasks?status=&agent_type=&limit=20&offset=0
```

响应参考 `api-standards.md` 统一格式，data 为任务列表数组。

### 6.2 新增：查询节点列表

```http
GET /api/v1/agent-nodes?status=&agent_type=&limit=50&offset=0
```

响应参考 `api-standards.md` 统一格式，data 为节点列表数组。
