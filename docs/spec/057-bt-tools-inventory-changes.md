  1. 库内被截断的 content（8000 字符）可解析出 58 个工具条目，按新格式渲染仅 **2,456 字符**

- 2026-09-27：**上限值按最坏情况收紧（150 → 50）**。复核时发现 150 字上限在
  「每条描述都触顶」的最坏情况下为 `164 × 98 = 16,072 字符 > 8,000`，会触发兜底截断、
  **重新丢工具名**。按 98×(2+名字20+1+风险6+2+上限) ≤ 8000 反推上限须 ≤ 55，取 50：
  最坏 `81 × 98 = 7,938 < 8,000`（硬保证），实测均值形态约 4,145 字符。
  补守卫用例 UT-74（算术保障）与 UT-74b（全部描述触顶时仍全量覆盖）。
